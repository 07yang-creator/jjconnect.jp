## 1. 復習ノート 第三部：待遇表現編（新增一部）

用户明确要求过（「语体梯度，否定请求，加入资料专题学习测试」）。
和现有两部并列，因为它考的是同一件事：同一个意思，根据对方和场合选哪一档。

| 小节 | 要点 |
|---|---|
| 敬语三系统 | いたします（谦让・自己）/ おります（谦让・自己）/ ございます（丁宁・无方向）/ なさいます（尊敬・对方）。方向错＝失礼 |
| 内外有别 | 对客户提到自己公司的社长也要用谦让语：「社長の山田は不在にしております」。**内外优先于上下** |
| 过去形四件套 | いらっしゃいました（尊敬）/ してくださいました（对方主动）/ まいりました（自己）/ していただきました（我请对方）。助词配对：くださる＝が、いただく＝に |
| 依赖的语体梯度 | てくれる → てくれない → てもらえる → てもらえない → ていただけますか → ていただけませんか → ていただけますでしょうか |
| 否定＝委婉的规律 | いいですか→よろしいでしょうか、できますか→難しいでしょうか、どうですか→いかがでしょうか |
| 委婉的三种手法 | 断定变疑问（のではないでしょうか）/ 肯定变否定（いただけませんか）/ 直说变推量（かと存じます） |
| 拒绝的梯度 | できません → 難しいです → いたしかねます → ご期待に沿えず |
| 常见误用 | ご利用できます（应为ご利用いただけます）/ お伺いいたします（二重敬語）/ お客様が申しておりました（谦让语用在客户身上）/ 部長はどちらにおりますか |
| クッション言葉 | 恐れ入りますが（轻）< お手数をおかけしますが（中）< ご無理を申し上げますが / 誠に勝手なお願いですが（重） |
| 敬语对照表 | する・いる・行く来る・言う・見る・聞く・食べる・知る・もらう・あげる 的三形式全表（会话里已列出） |

**题型要换**：这部分不适合纯填空。用两种——
① 给场景，从同一句话的四个敬语版本里选对客户用的那个；
② 四句里挑敬语方向错的那句（`set3` 第 48 题已有一个样例，可照抄格式）。

## 2. 復習ノート 第四部：発音・表記編（新增一部）

用户说「include these 2 in future summary」，指长音规律那两条。

| 小节 | 要点 |
|---|---|
| 拗音长音规律 | 汉字音读里 ゅ / ょ 几乎总是 ゅう / ょう。「きゅ」「ちゅ」单拍的汉字词基本不存在 |
| 段别长音写法 | う段・お段＋う（きゅう・しょう）、え段＋い（けい・せい・えい） |
| お段例外（写お） | とおり・こおり・おおきい・おおい・とおい・とお。**拗音没有写「お」的例外** |
| 短音组 vs 长音组 | 事務所・契約書・請求書・報告書・場所・住所（しょ短）↔ 証明・商談・承認（しょう长）。「請求書（せいきゅうしょ）」一词兼含两者 |
| 促音前不长 | 出発（しゅっぱつ）、出張（しゅっちょう＝前短后长）、一緒（いっしょ） |
| 具体订正过的词 | 充血 じゅうけつ / 柔軟 じゅうなん（非 じゅ）、求人 きゅうじん（非 きゅじん）、強化 きょうか（非 きゅうか）、強火 つよび、決して けっして（促音） |
| 音读训读两套 | 強：きょう（強化・強調）/ ごう（強引・強盗）/ つよ（強火・強気・強含み）/ し（強いる） |
| 人数的读法 | 一人ひとり・二人ふたり・四人よにん・九人きゅうにん、「人」在数量后读にん、抽象词读じん（法人・個人・代理人） |
| 火力 | 強火つよび・中火ちゅうび・弱火よわび・とろ火（只有中火是音读） |

**题型**：「选出正确读音」和「找出输入错误」（给四个假名串挑打不出字的那个）。

## 4. 新增的辨析组（可直接写进 fukushu 的第一部 / 第二部）

### 文型系

| 组 | 要点 |
|---|---|
| 乱れる / 崩れる / 潰れる / 汚れる | 秩序乱但形还在 ↔ 形垮掉 ↔ 压扁压垮 ↔ 变脏。ダイヤの乱れ / 体調を崩す / 会社が潰れる / 汚損（合同用语）。他动词：崩す有「破开钞票」义 |
| つかまえる / かかえる / おさえる / ささえる | 抓住不让跑 / 背着甩不掉 / 压低・占住 / 托着不倒。押さえる（会場を押さえる・物件を押さえる）vs 抑える（コストを抑える）。つかむ＝瞬间握住（コツをつかむ） |
| つもりだ | ①打算 ②自以为（確認したつもりでした＝解释失误用）③姑且当作。vs 予定（对客户承诺用予定或直接断定）。名词用法「どういうつもりですか」近乎质问 |
| おかげだ | おかげで / おかげだ / おかげさまで（寒暄固定语，不一定真有人帮忙）/ おかげをもちまして / 賜物（たまもの，致辞用）。可反讽，故书面慎用 |
| わけです | ①怪不得 ②也就是说。必须有前提。vs はずだ（时间向相反：わけ是结果→理由，はず是理由→结果）。书面换「ということになります」 |
| 言われた | ①被动 ②尊敬（同形！靠助词区分：に＝被动，が＝尊敬）③迷惑の受身（雨に降られる）。实务：「言われたので」→「ご要望を受けて」、「言われていません」→「伺っておりません」 |
| 言われています | 一般通说（无动作主）。vs とされています（明文・定说）/ と見られています（报道推测）/ とのことです（特定来源）。契约法令用「とされる」，世间通说用「言われる」 |
| のを / のか / こと | ①有疑问词→のか ②説明・報告・確認等「内容」动词→のか・こと・方法 ③知覚・待機・中止动词→のを。感官动词只能用の。失念（＝忘れる的郑重形） |
| 泳げなくなると系 | 可能形 vs 意志形：泳げない（能力）/ 泳がない（事实）/ 泳ごうとしない（不肯，**对第三者的非难**，不用于自己）。〜ようとする（正要）/ 〜ようとしても |
| てくる / ていく / てしまう | 変化の方向（改善してまいりました ↔ 改善してまいります）。てしまう＝不本意，用在理由侧可软化拒绝：「間に合わなくなってしまうためです」 |
| 割には / にしては | にしては前面要具体基准（五十歳にしては）、割には可接笼统程度（年齢の割には）。实务：費用対効果、〜に見合う |
| ぐらいなら（已在 benseki）+ ほど | ほどだ / ほどの / ば〜ほど / ほど〜ない / 数量＋ほど。**商务最高频的是クッションの「ほど」**：ご確認のほど・ご査収のほど（无程度义，只为软化，必配よろしくお願いいたします） |
| もしかしたら | 呼应かもしれない。もしかして＝向对方确认。书面换「〜可能性がございます」。vs 万が一（坏事假定）/ 仮に（议论假定）。行き違い（催促后对方正好回信时的万能缓冲） |
| にくい形に / という形で | 〜にくい＋形（方式・体裁）。「書面の形で」「業務委託という形で」「覚書という形で」。提案书对比句式：起きやすい→防ぎやすい形に |
| だけなので | ので接名词・ナ形要「な」。だけ / ばかり（净是，负面）/ しか〜ない（不足）/ のみ（公文）。だけあって（不愧是）vs だけに（程度相应） |
| わけでもない | わけ四兄弟：わけだ / わけではない / わけがない / わけにはいかない（立场上不能，谦让形「わけにはまいりません」） |
| 末に | すえ（〜た末に＝经过曲折后）vs まつ（月末・年度末）。vs あげく（结果徒劳或更坏）。**年度末＝3月31日 ≠ 年末** |
| 無理に | 無理に / 無理やり。ご無理を申し上げますが。「無理です」→「いたしかねます」「困難」（不用「不可能」，留余地） |
| その他にも | また（同格）/ なお（本题外的补充）的分工。法令用法：「A その他の B」＝A⊂B，「A その他 B」＝并列（不动产合同里实际会用到） |
| いちいち | 事事都（烦）。中立替换：一つ一つ / 都度 / 逐一。「いちいちもっともだ」是唯一不带负面的用法 |
| いまだに | 至今未（带不满）。vs 一向に（更强）/ 依然として（书面中性）。未着・未定・未処理・未入金・未対応（系统台账常见） |
| まだ系 | まだ / まだまだ（自谦）/ ならまだしも / もう との对立（もう＋否定＝已经不） |
| やり系 | 目的的「に」只能接移动动词（本を買いに行く ○ / 買いに勉強する ✕）。やり方・やり取り（无郑重替代，正式场合直接用）・やりがい・やり繰り（金钱用資金繰り）・やり過ごす・〜っぱなし |
| くれない | ①くれる的否定（带埋怨）②请求形（语体梯度见第 1 节）③暮れない（途方に暮れる） |
| とあれこれ考えた | 引用的と（〜と思う / と言う / とのこと / かと存じます / 〜ばと存じます）。あれこれ / いろいろ / さまざま / 何かと / 諸般（諸般の事情により＝公告里的「因故」） |
| 決して | 副词呼应：決して〜ない / 必ずしも〜とは限らない / 二度と〜ない（道歉信：二度とこのようなことがないよう） |
| こうして見ると | 补助动词不重复（✕こうしてみてみると）。〜てみると / てみれば / **てみたところ**（书面：確認してみたところ） |
